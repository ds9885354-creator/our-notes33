Quick Setup Instructions

3 simple steps to make the app accessible

1 Generate GitHub Token (Secret Key)

1. Open GitHub.com > Settings > Developer Settings > Personal Access Tokens (Classic).
2. Click Generate New Token.
3. Check the gist checkbox ✅.
4. Copy your key (starts with ghp_) into Box 1!

2 Host on GitHub Pages (Free)

1. Create a repository named our-notes33 on GitHub.
2. Upload this HTML file as index.html.
3. In Repo Settings > Pages, select the main branch and click Save.

3 Paste Gist ID on Both Phones
